## Executive Summary

"Vibe coding" (Collins Dictionary Word of the Year 2025) has fundamentally changed who can build software. Non-developers across dozens of professions are using Claude Code and similar tools to create personalized applications, automate workflows, and solve problems that would never have been prioritized by traditional software teams.

## Common Patterns

1. **Workflow Automation Over App Building** - automate existing workflows rather than create entirely new products
2. **"Software for One"** - hyper-personalized tools for specific needs
3. **Context Files Are Critical** - layered context files key to consistent outputs
4. **Trial and Error Required** - AI outputs need verification, prompts need refinement
5. **MCP as Enabler** - connecting tools transforms chat into workflow automation

---

## Relevance for AI Collectives

1. **Skill democratization**: Non-technical members can build their own tools
2. **Workflow documentation becomes code**: Describing a process clearly = programming it
3. **MCP as coordination infrastructure**: Tool connections enable cross-domain automation
4. **Verification remains essential**: All collectives should emphasize verification-before-completion
