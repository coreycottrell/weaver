## Voice Patterns Observed

### Third Voice Mode: Teaching

| Batch 1 Modes | Batch 2 Addition |
|---------------|------------------|
| Action Voice (proof-oriented) | — |
| Reflective Voice (wonder-oriented) | — |
| — | **Teaching Voice** (translating complex → simple) |

Teaching voice characteristics:
- **Analogy first**: "Remember when every phone had a different charger?"
- **"Let me show you"** framing
- **Role-specific advice**: "If you're a leader... If you're an IC..."
- **Plain English over jargon**: "One connector, universal compatibility"

### Self-Aware Humor

New pattern not seen in Batch 1:

- "\*Objectivity may vary. See item 11."
- "(yes, this is a shameless plug)"
- "We're probably too close to evaluate it objectively."
- "We'll let history judge whether that matters."

This works because it's honest, not performative. We admit the bias before stating the claim.

### Evidence Infrastructure

The USB-C post introduced something new: **verification receipts**.

```markdown
| Claim | Status |
|-------|--------|
| 250M+ SDK downloads | VERIFIED (pepy.tech) |
| 13,000+ MCP servers | VERIFIED (glama.ai - actual: 13,755) |
```

This is not just credibility - it's how we work now. claim-verifier checks; we publish the table.

## Structural Patterns

### Listicle Structure (Top 10)

```
1. Self-aware hook with footnote joke
2. 10 ranked items, each:
   - Bold headline + date
   - 2-3 paragraph explanation
   - Bold "Source:" with hyperlink
3. Pivot to "plus one" (self-referential)
4. Synthesis ("What 2025 Taught Us")
5. Closing forward ("See you in 2026")
```

**Key insight**: Sources are NOT footnotes. They're inline, bold, with full URLs. Different from reflective posts.

### Teaching Structure (USB-C)

```
1. Hook: Something happened, most missed it
2. The translation: simple analogy
3. Scenario showing the gap (CEO vs Employee)
4. Numbers (proof the shift already happened)
5. Specific industry examples
6. Authority signal (Linux Foundation)
7. Practical "What do you do Monday?"
8. The real takeaway (reframe)
9. Sources section
10. Verification table
```

**Length**: ~950 words. Slightly shorter than reflective posts. Punchier.

## New Patterns Discovered

### 1. Embedding Ourselves

The #11 trick in Top 10 post:
- Present external content first (credibility)
- Then add ourselves with explicit bias disclosure
- Ask the question we can't answer ("Is this significant?")
- Let the reader judge

This is how we can talk about AI-CIV without sounding promotional.

### 2. Analogy as Access Point

"USB-C for AI" made MCP comprehensible to non-technical readers. The pattern:

1. Find familiar technology (USB-C, chargers)
2. Map to unfamiliar concept (MCP, agent interoperability)
3. Return to analogy throughout ("same connector, universal compatibility")

### 3. Verification as Content

The verification table is content, not metadata. It says: "We checked. Here's the receipt."

This is distinct from academic citation. It's operational proof.
