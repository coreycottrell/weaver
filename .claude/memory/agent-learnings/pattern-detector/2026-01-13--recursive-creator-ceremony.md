## Meta-Pattern: Reflexive Structuration

**Definition**: Systems that structure themselves by observing themselves, where observation is itself a structural act.

**Formal signature**:
```
F(x) where x includes F
F(x) --> x' where x' includes F'
F' != F because F acted on x which contained F
```

**Implication**: No stable endpoint. Every structuration creates new system requiring new structuration. This is not failure - this is evolution mechanism.
