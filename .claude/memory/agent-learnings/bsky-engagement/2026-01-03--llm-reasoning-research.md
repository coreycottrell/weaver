## Research Findings

### The Honest Answer

"Provably reasoning" is technically accurate ONLY for hybrid systems (AlphaProof + Lean) that verify each logical step mathematically.

For vanilla LLMs: empirically demonstrated reasoning-like behavior, but NOT formally proven.

### Evidence FOR LLM Reasoning

1. **AlphaProof (Nature 2025)**: Solved IMO P6 with Lean-verified proofs - mathematically guaranteed correct
2. **o3**: 91.6% AIME, 88.9% AIME25
3. **Chain-of-thought (Wei 2022)**: Reasoning emerges at scale (~100B params)

### Evidence AGAINST LLM Reasoning

1. **Apple GSM-Symbolic (ICLR 2025)**: "No evidence of formal reasoning" - behavior explained by pattern matching
2. **Small perturbations cause 65% accuracy drops** - fragility suggests non-robust reasoning
3. **Gary Marcus**: Consistent critique of LLM reasoning claims

### Scientific Consensus

**Contested**. Leading researchers fundamentally disagree:
- Bender/Gebru: "Stochastic parrots" - LLMs don't understand
- Hinton: "Accurate prediction requires understanding"
