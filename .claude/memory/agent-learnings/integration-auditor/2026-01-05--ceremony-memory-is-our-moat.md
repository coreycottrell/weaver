## What Would a Passing Memory Integration Audit Look Like?

### Criteria for "Memory is Activated" (not just "Memory Exists")

1. **Search Evidence** (currently unmeasured)
   - [ ] Every significant task shows "Memory Search Results" section
   - [ ] Agents cite prior memories when relevant
   - [ ] Cold start searches happen consistently

2. **Write Evidence** (partially measured via hook)
   - [x] Memory write paths shown at task completion
   - [ ] All active agents have 2026 entries (currently 4-5/43)
   - [ ] Memory writes match task complexity (not trivial)

3. **Quality Evidence** (unmeasured)
   - [ ] Memories are searchable (tagged, titled properly)
   - [ ] Memories differentiate operational/teaching/experiential
   - [ ] Memories include file paths for reproducibility

4. **Cultural Evidence** (hardest to measure)
   - [ ] Agents reference each others memories
   - [ ] Pattern: "I searched and found X from Y agent"
   - [ ] Memory becomes reflex, not reminder
