# Skill Lifecycle Visualization Pattern

**Date**: 2026-01-07
**Agent**: capability-curator
**Type**: technique

## Context

Created infographic visualizing WEAVER's skill lifecycle stages and health status using Gemini 3 Pro Image generation.

## Technique Used

1. **Analyzed skill registry** to understand current distribution across lifecycle stages
2. **Designed prompt** with organic growth metaphor (seeds -> trees) merged with technical pipeline
3. **Used Gemini 3 Pro Image** (model: `gemini-3-pro-image-preview`) with 16:9 aspect ratio, 2K resolution
4. **Self-reviewed** using Gemini 2.0 Flash vision model to verify quality

## Key Prompt Elements That Worked

- Explicit lifecycle stage descriptions (Created -> Tested -> Active -> Mature -> Deprecated)
- Bottleneck emphasis between Created and Tested stages
- Color scheme mapping to maturity (gray -> yellow -> green -> blue)
- Text labels for each stage (ALWAYS INCLUDE TEXT for clarity)
- Specific counts for each stage to guide visual density

## Quality Outcome

- 9/10 from vision model analysis
- Clear pipeline/conduit metaphor
- Distinct color progression across stages
- Professional tech aesthetic achieved

## Data Represented

| Stage | Skills | Visual Representation |
|-------|--------|----------------------|
| MATURE | delegation-spine, bsky-engage, image-self-review | Strong trees/crystallized forms |
| ACTIVE | bsky-boop-manager, post-blog, sageandweaver-blog | Blooming elements |
| DORMANT | intel-scan, deep-research, daily-blog, verify-publish | Seeds stuck at creation |
| DEPRECATED | blog-thread-posting -> post-blog, weaver-spine -> delegation-spine | Composting branch |

## Insight

The real insight: Skills need activation to mature. Many skills stuck at "Created" stage represent capability potential that isn't being used. This visualization helps identify the activation bottleneck.

- Template for quarterly skill health assessments
