## Technique: Network Visualization for Ecosystem Architecture

### When to Use
- Visualizing interconnected systems
- Showing relationships between components
- Representing active vs dormant elements
- Illustrating consolidation/merger patterns

### Design Elements

1. **Central Hub**: Foundation element at center with brightest glow
2. **Orbital Clusters**: Related components grouped together
3. **Color Coding by Status**:
   - Cyan/Teal = Active, working
   - Purple/Magenta = Consolidating, merging
   - Grey/Blue = Dormant, potential
   - Gold = Foundation, supporting
4. **Connection Types**:
   - Bright lines = Active connections
   - Dotted lines = Potential/planned connections
   - Dim lines = Dormant connections
5. **Depth Layers**: Foreground (active), middle (clusters), background (foundation)

### Prompt Structure for Gemini Image Generation

```
1. Overall structure description (hub + clusters)
2. Each cluster with:
   - Position (upper left, upper right, bottom)
   - Color/glow characteristic
   - Node arrangement (triangle, linear, merger)
   - Status indicator (active, dormant, consolidating)
3. Connection types between clusters
4. Style directives:
   - Background (dark, grid)
   - Aesthetic (bioluminescent, tech, organic)
   - Quality (high contrast, crisp)
5. Text overlay with key stats or labels (ALWAYS INCLUDE TEXT)
```

### Key Learning

For ecosystem visualizations:
- Use spatial arrangement to show relationships
- Color = status/health indicator
- Node size = importance
- Connection brightness = activity level
- Central hub shows what everything depends on
