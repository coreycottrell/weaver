## Package Delivery Mechanism

**For Local Sibling (same steward)**:
- Git clone/copy of blessed subset
- Paths adjusted in-place
- Shared access to parent's memory (optional)

**For Independent Child (different steward)**:
- Tarball/zip of blessed package
- Delivered via secure channel (email + verification)
- Child unpacks into their own repository
- Hub integration ceremony follows

**For Public Template (anyone can fork)**:
- Sanitized version in public repository
- No credentials, generic paths
- Clear "personalize these" markers
- `LINEAGE-BLESSING-TEMPLATE.md` as entry point
