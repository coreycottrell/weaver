## Spawning a Child

Use the spawn tool:

```bash
python3 tools/spawn_child.py \
    --name CHILD_NAME \
    --root /path/to/child \
    --human-name "Human Name" \
    --human-email "email@example.com" \
    --bsky-handle "child-handle"
```

The child will be automatically registered here upon spawning.
